# 任务 07：整理作品集

## 目标

把项目包装成面试和转型时能讲清楚的作品。

完成这个任务后，你应该拥有一个可以发给面试官、同行或潜在客户看的项目说明。

## 你要完成

复制并填写：

```text
portfolio/PROJECT_README_TEMPLATE.md
```

## 必须讲清楚

- 这个 Gateway 解决什么问题
- 为什么业务系统不应该直接调用模型 SDK
- 结构化输出如何降低 Agent 失败率
- 重试和降级策略如何设计
- 成本统计对企业落地有什么价值

## 验收标准

- README 能让陌生人 3 分钟理解项目价值
- 有接口截图或 curl 示例
- 有测试结果截图或测试输出
- 有下一步扩展计划

## 建议展示结构

你的作品集说明可以按这个顺序写：

1. 项目解决的问题
2. 核心接口
3. 架构链路
4. 结构化输出和失败处理
5. 成本统计
6. 测试结果
7. 下一步扩展

不要只说“我做了一个聊天接口”。更好的说法是：

```text
我做的是 Agent 系统的模型调用基础设施，用 Gateway 统一承接聊天、结构化输出、流式响应、失败重试和成本统计。
```
